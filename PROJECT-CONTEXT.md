# Agentic RAG Research Assistant — Context

## Goal
Agentic RAG project using LangGraph for fresher GenAI/ML roles.
LLM agent autonomously decides retrieval strategy, query rewriting, 
and self-correction.

## Tech Stack (All FREE)
- Python 3.11.9, Windows
- LangGraph 0.2.45 (agent orchestration)
- LangChain 0.3.7
- Ollama (llama3.1:8b) — LLM
- all-MiniLM-L6-v2 — embeddings
- FAISS — vector DB
- Streamlit — UI
- RAGAS — evaluation
